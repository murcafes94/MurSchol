# MurSchol OS Desktop

Futuro sistema para PC.

## Dirección técnica inicial

- Kernel Linux y base mínima aún por decidir.
- Escritorio/shell propio de MurSchol.
- Aplicaciones académicas, navegador, Moodle y herramientas de productividad.
- Objetivo de funcionar bien también en equipos de recursos modestos.

La interfaz deberá mantener el mismo lenguaje visual y de navegación de MurSchol Mobile.
