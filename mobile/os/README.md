# MurSchol OS Mobile

Futuro sistema para tablet y teléfono.

## Dirección técnica inicial

- Base Android/AOSP para conservar compatibilidad con aplicaciones Android.
- Interfaz MurSchol compartida con MurSchol Launcher.
- Enfoque en estudio, lectura, Moodle, multimedia y bajo consumo.
- MurSchol Safe evolucionará aquí hacia una política real de sistema.

La fase actual consiste en validar primero la experiencia con `mobile/launcher/` sin modificar el sistema del dispositivo.
